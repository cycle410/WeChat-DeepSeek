# WeChat-DeepSeek

微信 AI 聊天机器人，基于 DeepSeek API + 微信官方 iLink Bot

</div>

---

## 快速开始

```bash
npx WeChat-DeepSeek
```

终端显示二维码，微信扫码即用。首次运行会引导配置 API Key。

---

## 配置

支持三种方式，优先级从高到低：

1. **命令行参数** — `--api-key` / `--model`
2. **环境变量** — `DEEPSEEK_API_KEY`
3. **配置文件** — `.config/config.json`（首次交互式配置自动生成）

`.config/config.json` 里可用的字段：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `model` | `deepseek-chat` | 模型名，如 `deepseek-v4-flash` |
| `baseUrl` | `https://api.deepseek.com/v1` | 接口地址 |
| `thinking` | 未设（跟随服务端，开启） | 设为 `"disabled"` 关闭思考模式：同一问题实测 107 → 38 token，更快更省 |
| `maxTokens` | `4096` | 单次回复上限；思考开着时，思考也算在这个额度里 |
| `timeoutMs` | `120000` | 单次请求超时（毫秒） |

## 特性

- 微信官方 iLink Bot API，非 hook，零封号风险
- API 密钥 AES-256-CBC 加密存储，绑定本机
- Session 过期自动重连，指数退避，最多 5 次
- 对话历史持久化，支持 `/clear` 清空、`/历史` 查概况
- 每用户限流：3 秒冷却 + 每分钟 10 条
- 思考模式可关（`thinking: "disabled"`），同一问题省约 60% token
- 配置文件带 BOM 也能读，用记事本改配置不会失效
- 零外部依赖，仅需 Node.js 18+

## 内置命令

| 命令 | 功能 |
|------|------|
| `/clear` | 清空对话历史 |
| `/历史` | 查看当前对话历史概况（条数 / 字数） |
| `/help` | 显示帮助 |
| `/ping` | 检查在线状态 |
| `/status` | 运行状态概览 |
| `/搜 关键词` | 联网搜索并总结，附来源链接 |
| `/读 链接` | 读取网页正文并总结 |

联网命令也可以不带斜杠：`搜一下 xxx`、`搜索 xxx`、`读一下 链接`。

## 联网搜索

搜索与网页读取走 DeepSeek 官方 API（与聊天同一把 Key）：

| 能力 | 接口 | 计费 |
|------|------|------|
| 搜索 | `POST /v1/tools/search` | 成功且有结果 5 元/千次 |
| 读网页 | `POST /v1/tools/fetch` | 成功 5 元/千次 |

- 只有「成功且有内容」才计费，失败/空结果/超时不收费
- 搜索词支持 `site:`、`-site:`、`"精确短语"`、`lang:zh`、`after:2025-01-01` 等语法
- 搜索结果先由模型整理，再连同「标题 + 链接」一起回复
- 联网请求不写入角色对话历史，不影响人设
- 限流与普通消息一致（3 秒 / 每分钟 10 条）

## 常见问题

| 问题 | 解决 |
|------|------|
| node 命令找不到 | 重新安装 Node.js |
| 二维码扫不了 | 拉宽终端窗口，或复制链接到浏览器 |
| 扫码后没反应 | iOS 需微信 8.0.70+，安卓按提示更新 |

---

## 说明

- Bot 仅接收用户主动发送的消息，无法监听群聊或冒充个人号
- 所有数据本地处理，不经过第三方
- 支持 iOS 微信 8.0.70 以上及安卓平台
- **系统提示词是通用助手版**。想换成自己的人设，直接改 `lib/ai.mjs` 里的 `SYSTEM_PROMPT`
- `.config/` 永远不入库：里面有微信登录 token、API Key、对话历史
